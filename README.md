This is a POS (point of sale system for a general store. This is made with C++ as the group project sunbmission for the OOPS subject.
This software handles inventory, billing and helps manage the store.
Since the core concepts of object oriented programming aren't used much in such systems, and this is a project for OOPS, we decided to first load
all data from the permanent storage to the ram using vectors and classes, thus mitigating the existential crisis of this project.
